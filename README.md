# My Career Choice as a fresh grad of CS

I am confused about my career choice in 2026. Not because I don't know anything about CS, but because I want job that has easier entry barrier level for freshers.
Now you might think there would be no job like that in 2026, but when you compare jobs like data engineering, data scientists, ML/Dl engineering and cloud engineering etc to software engineering jobs like full stack web developer, android developer, backend developer, ios developer and cross-platform developers, the supply of people in the first category (Non SE roles) is comparitively less than softwares engineers, though the first category has a higher entry barrier, which simply means companies would rather prefer individuals who already have some IT background experience over hiring fresh cs graduates (or se/it graduates, cs is just an umbrella for both).
